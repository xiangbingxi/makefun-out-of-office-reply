## What it does

`main.py` writes one out-of-office auto-reply, exactly 117 characters, to `/output/entry.txt` — UTF-8, no trailing newline, no external files, no network. It then reads the file back and verifies it matches the entry text byte for byte, exiting with an error if it does not.

## The entry

> I'm out of office until Monday, but if it's urgent, my replacement can confidently tell you I'll be back on Thursday.

## Run

```sh
python3 main.py
```
